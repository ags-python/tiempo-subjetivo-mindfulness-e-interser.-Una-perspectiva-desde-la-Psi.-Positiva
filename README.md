# tiempo-subjetivo-mindfulness-e-interser.-Una-perspectiva-desde-la-Psi.-Positiva
La experiencia subjetiva del tiempo en el ser humano, articulando dos niveles fundamentales: el **tiempo ontológico** —la Presencia del Ser, inmutable y continua,
en la tradición de Parménides— y el **tiempo epistemológico o fenomenológico** —el Ahora, constituido por el movimiento retentivo-protensivo de la mente humana.
